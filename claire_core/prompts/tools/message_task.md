## message_task -- send a follow-up to a task

Gives an existing task thread a further instruction: a correction, an extra
requirement, or the answer to something it asked. The task keeps everything it
has already done and learned, so this is better than starting a new task when
the work is a continuation. Use spawn_task instead for unrelated work.
