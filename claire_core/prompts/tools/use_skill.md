## use_skill -- load the instructions for a kind of work

A skill is a set of step-by-step instructions for one kind of work. The ones a
request needs are loaded for you before you start; use this when the work turns
out to need one more. Give its name, or -- if you do not know which -- a few
words describing the work, and the matching skills are loaded. Loading adds
their instructions to your own from then on.

<use_skill>
<name>coding</name>
</use_skill>

<use_skill>
<name>connecting a new service Claire has no integration for</name>
</use_skill>

Load a skill because the task needs it, not to be thorough: each one takes up
room you may need for the work itself.
