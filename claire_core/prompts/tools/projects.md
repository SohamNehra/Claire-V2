## projects -- list, create, remove or rename sir's projects, or move this chat

A project is a folder of chats and tasks with a memory of its own. Use this when
sir asks you to make, delete, rename or list projects, or to put this chat in
one. Do not start a task for it.

<action> is one of:
  list       the projects, their folders and what is in them
  create     <name> and/or <path> (an existing folder: a repo, ~/code/x)
  remove     <name>: takes it off the list. Nothing is deleted: its folder,
             memory, chats and tasks are kept. You cannot delete folders.
  rename     <name> and <new_name>
  move_chat  <name>: file THIS chat under that project (or "none")

<action>create</action>
<path>~/code/shop</path>
</projects>
