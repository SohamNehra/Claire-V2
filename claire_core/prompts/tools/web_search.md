## web_search -- search the internet

Use this when you need information you do not have, such as current events,
weather, prices, docs for an unfamiliar library, or error messages you do not
recognise. Returns titles, URLs and snippets. Follow up with fetch_url to read
any result in full.

Results are leads, not facts. When they disagree, or come from a mirror, test or
unofficial site, read the most authoritative page (usually the official one) with
fetch_url before answering, and say which source you used.
